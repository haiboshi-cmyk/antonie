# 企业服务 Agent 业务上下文

这是一个可公开复用的 AI Agent 上下文包，帮助其他 Agent 快速理解团队的业务范围、目标客户、能力路由、工作习惯、安全边界和交付标准。

## 文件结构

| 文件 | 用途 |
|---|---|
| [AGENTS.md](./AGENTS.md) | Agent 必读入口；默认流程、风险边界和数据规则 |
| [行业画像.md](./行业画像.md) | 业务定位、客户、业务线和区域范围 |
| [技能总索引.md](./技能总索引.md) | 按任务选择能力并核对前置条件 |
| [工作习惯.md](./工作习惯.md) | 沟通、交付、自动化协作和质量偏好 |

## 使用方法

1. 将这些文件复制到目标项目根目录。
2. 让 Agent 先读 AGENTS.md。
3. 根据任务再读其他三份文件，不要一次加载无关内容。
4. 使用技能前确认当前环境已安装并完成所需登录或连接。

支持 AGENTS.md 的 Agent 通常会自动读取；其他 Agent 可将这些 Markdown 文件导入系统提示或知识库。

## 公开边界

本仓库不包含客户名称、联系方式、账务数据、证件信息、内部私人目录、登录凭据、API 密钥、客户名单或招聘采集数据。

本仓库用于业务上下文和协作约束，不构成税务、法律或监管意见。实际办理前应按地区、主体、所属期和最新官方规则复核。
