# 企业服务 Agent 业务上下文

这是一个可公开复用的 AI Agent 上下文包，帮助其他 Agent 快速理解团队的业务范围、目标客户、能力路由、工作习惯、安全边界和交付标准。

## 文件结构

| 文件 | 用途 |
|---|---|
| [AGENTS.md](./AGENTS.md) | Agent 必读入口；包含默认流程、风险边界和数据规则 |
| [行业画像.md](./行业画像.md) | 业务定位、客户、业务线和区域适用范围 |
| [技能总索引.md](./技能总索引.md) | 按任务选择能力，并核对前置条件和可用状态 |
| [工作习惯.md](./工作习惯.md) | 沟通、交付、自动化协作和质量偏好 |
| [办理总控.md](./办理总控.md) | 从客户需求到办结归档的统一流程、分流和状态规则 |
| [业务受理单模板.md](./业务受理单模板.md) | 把聊天或口头需求转成结构化任务 |
| [Agent单任务执行卡模板.md](./Agent单任务执行卡模板.md) | 供 Agent 一次执行一个客户的一项业务 |
| [提交前复核清单.md](./提交前复核清单.md) | 正式提交前的通用与分业务检查 |
| [办结与回执模板.md](./办结与回执模板.md) | 核验最终状态、留存证据并回写台账 |

## 使用方法

1. 将这些文件复制到目标项目根目录。
2. 让 Agent 先读 `AGENTS.md`。
3. 收到实际业务时，先用 `办理总控.md` 分流，再建立 `业务受理单模板.md`。
4. 资料齐全后，复制 `Agent单任务执行卡模板.md`，每张卡只处理一个客户的一项业务。
5. 正式动作前完成 `提交前复核清单.md`；提交后用 `办结与回执模板.md` 留痕。
6. 使用技能前确认当前环境已安装并完成所需登录或连接。

支持读取 `AGENTS.md` 的 Agent 通常会自动把它作为项目级协作说明；其他 Agent 可将这些 Markdown 文件导入系统提示或知识库。

## 公开边界

本仓库不包含客户名称、联系方式、账务数据、证件信息、内部私人目录、登录凭据、API 密钥、客户名单或招聘采集数据。

本仓库用于业务上下文和协作约束，不构成税务、法律或监管意见。实际办理前应按地区、主体、所属期和最新官方规则复核。
