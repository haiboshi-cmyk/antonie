# 企业服务 Agent 业务上下文

这是一个可公开分享的 AI Agent 上下文文件，概括团队的业务能力、目标客户、工作方式、安全边界和交付标准。

## 使用方法

将 [`AGENTS.md`](./AGENTS.md) 放到目标项目根目录。支持读取 `AGENTS.md` 的 Agent 会把它作为项目级协作说明；其他 Agent 可将其作为系统提示或知识库文档导入。

## 内容范围

- 服务对象：北京、海南的中小微企业，以及财务公司和企业服务机构。
- 业务方向：财税、工商、合规、经营分析、客户服务、AI 辅助办公和流程自动化。
- 操作原则：权威来源、客户隔离、最小数据、人工复核、回执闭环。

本仓库不包含客户名称、联系方式、账务数据、证件信息、内部文件路径或登录凭据。

## 使用提醒

本文件用于提供业务上下文和协作约束，不构成税务、法律或监管意见。实际办理前应根据地区、主体、所属期和最新官方规则复核。
